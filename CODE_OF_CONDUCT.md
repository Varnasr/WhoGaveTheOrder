# Code of Conduct

This project records how state power is used against citizens. People who read
it and work on it include those who were affected. We expect everyone to be
respectful and careful, to attribute every allegation to whoever makes it, to
name no private individual, and to accept correction. Harassment, personal
attacks, doxxing and discriminatory language are not acceptable.

Report concerns to care@pinpointventures.in. We will acknowledge a report within
48 hours.
